## 🌟 Overview

**T-Shirt WebGL Shader** is an immersive creative web project designed for interactive e-commerce and creative portfolio hero sections. It leverages custom shader algorithms and **React Three Fiber** to render realistic fabric textures, dynamic sheen, and customizable colors in real time.

- 🔗 **Live Demo:** [https://t-shirt-shadder.vercel.app](https://t-shirt-shadder.vercel.app)
- 👤 **Author:** [Erum Khan (@erum-dev-max)](https://github.com/erum-dev-max)

---

## 🚀 Key Features

- 🧵 **Dynamic Fabric Shaders:** Procedural shading simulating realistic cloth weave, diffuse lighting, and fold contours.
- 🎨 **Real-Time Color & Texture Customization:** Instant UI feedback allowing users to tweak surface tones and graphics.
- 🎥 **Smooth Orbit Controls:** Natural camera damping allowing full ^\circ$ inspection with zoom and pan limits.
- ⚡ **Optimized Rendering Pipeline:** Runs smoothly at 60 FPS across both desktop and mobile web browsers.

---

## 🛠️ Tech Stack

- **Framework:** React, TypeScript, Vite
- **3D & Graphics:** Three.js, React Three Fiber (@react-three/fiber), React Three Drei (@react-three/drei)
- **Shaders:** GLSL (OpenGL Shading Language) / Custom Fragment & Vertex Shaders
